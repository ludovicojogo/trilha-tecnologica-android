# Trilha Tecnológica — Android

Versão Android final do jogo da Feira das Profissões.

## Incluído
- Jogo executado 100% local dentro do APK.
- Banco de perguntas local.
- Ranking local via `localStorage`.
- Exportação do ranking em CSV.
- CSS local, sem dependência de internet.
- Confete local.
- Áudio local via Web Audio API.
- Atalhos 1–6 para dado e 1–3 para respostas.
- Responsividade para celular, tablet, notebook, TV e projetor.
- Tela cheia imersiva.
- Tela mantida ativa durante a apresentação.
- Rotação e redimensionamento suportados.
- Sem permissão de internet.

## APK
O GitHub Actions gera automaticamente o artefato **Trilha-Tecnologica-APK** em cada push para a branch principal.
